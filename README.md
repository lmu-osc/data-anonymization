# Data Anonymization Course

A self-paced tutorial from the LMU Open Science Center on anonymizing quantitative research data. It takes about three hours and covers the legal and ethical foundations of data protection, a step-by-step anonymization process using the `sdcMicro` R package and a simulated dataset, and strategies for balancing privacy against openness. It assumes basic R skills and focuses exclusively on quantitative tabular data.

The tutorial is a Quarto website built with the [`lmu-osc/tutorial-template`](https://github.com/lmu-osc/tutorial-template) extension. Render it with `quarto render`. The content is licensed under CC BY-SA 4.0 and the code under CC0 1.0; see [CITATION.cff](CITATION.cff) for how to cite it.
